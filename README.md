## Featured Projects

### 📊 Filing Intelligence · AI research over SEC 10-K filings
Ask questions about 191 company annual reports and get answers backed by sources. A LangGraph workflow routes each question, searches a ChromaDB index, checks that each excerpt is relevant, and writes the answer. Financial ratios and trends are calculated in plain Python, not by the model, so the numbers can be checked.

*Python · LangGraph · ChromaDB · Streamlit · Plotly · GitHub Actions*
**[View repository →](https://github.com/omarhicham44-ux/sec-financial-rag-omar)**

### 🎲 Jackaroo · Board game in Java
A full Jackaroo board game with a playable desktop interface. The game logic is modeled with OOP and kept separate from the interface using MVC, and every move is validated against the rules.

*Java · JavaFX · OOP · MVC*

### 🗂️ HR Management System · Database project

*SQL Server · SQL · EERD · Web*

*Java · TCP/IP · Sockets · Wireshark*
